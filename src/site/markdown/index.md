# 法人マスタ管理システム

## プロジェクト概要

ドメイン駆動設計（DDD）アーキテクチャ原則に基づいて構築された法人マスタデータ管理システムです。
法人情報の管理と、データ変更に対する承認ワークフローを提供します。

## 主要機能

- **法人マスタデータ管理**: 法人の基本情報、連絡先、住所、口座情報の管理
- **承認ワークフロー**: 法人データ変更の申請・承認・却下プロセス
- **ロールベースアクセス制御**: 営業担当者、部長、システム管理者の権限管理
- **監査証跡**: 全ての変更履歴の記録と追跡
- **多言語対応**: 日本語メインの国際化対応

## 技術スタック

### バックエンド
- **Java 17** (LTS)
- **Spring Boot 3.2.1**
- **Spring Security** (JWT + セッションベース認証)
- **Spring Data JPA** with Hibernate
- **PostgreSQL** (本番) / **H2** (テスト)

### テスト
- **JUnit 5** - 単体テスト
- **Mockito** - モックテスト
- **jqwik** - プロパティベーステスト
- **JaCoCo** - コードカバレッジ

### 品質管理
- **Maven Surefire** - テスト実行・レポート
- **JaCoCo** - コードカバレッジ測定
- **Maven Site** - 統合レポート生成

## アーキテクチャ

このプロジェクトは**ドメイン駆動設計（DDD）**とクリーンアーキテクチャの原則に従い、
以下のレイヤー構造で組織化されています：

- **ドメイン層**: コアビジネスロジック（純粋なドメインモデル）
- **アプリケーション層**: ユースケースの実装
- **インフラストラクチャ層**: 外部システムとの連携
- **プレゼンテーション層**: REST APIエンドポイント

## ドメイン領域

### 法人管理 (Customer)
- 法人プロファイル管理
- 連絡先情報管理
- 住所管理
- 口座情報管理

### 営業部門管理 (SalesDepartment)
- 部門構造管理
- メンバー管理
- 部長権限管理

### ユーザー管理 (User)
- 認証・認可
- ロール管理
- アカウント管理

### 担当者割り当て (Assignment)
- 担当者変更申請
- 承認権限管理
- 変更履歴管理

### 承認ワークフロー (Approval)
- 変更申請プロセス
- 承認・却下処理
- 期限管理

## 開発・運用

### 開発環境
```bash
# 開発環境起動
scripts\start-dev-env.cmd

# アプリケーション起動
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

### テスト実行
```bash
# 全テスト実行
./mvnw test

# カバレッジレポート生成
./mvnw jacoco:report

# サイトレポート生成
./mvnw site
```

### レポート確認
- **テスト結果**: `target/site/surefire-report.html`
- **カバレッジ**: `target/site/jacoco/index.html`
- **統合レポート**: `target/site/index.html`
